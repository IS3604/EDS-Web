# EditSimple website

Static site hosted on GitHub Pages: https://is3604.github.io/EDS-Web

## Folder layout
- `*.html` – the published pages (generated by `build.py`, don't edit by hand)
- `src/layout.html` – header, footer and the lead popup shared by every page
- `src/pages/<name>.html` – the main content of each page
- `assets/site.css` – all styles · `assets/site.js` – all interactions · `assets/config.js` – where form submissions are sent
- `images/` – images used by the site
- `blog.html`, `blog/<slug>.html` – blog pages (generated); `blog/posts/<slug>.json` – post content
- `sitemap.xml`, `robots.txt` – generated by `build.py`
- `.github/workflows/build-site.yml` – rebuilds the pages when a blog post is published

## Editing
1. Change text in `src/pages/<name>.html` (or `src/layout.html` for header/footer/popup).
2. Run `python build.py` to regenerate the `.html` pages.
3. Page titles and descriptions are set in `build.py`; the site address is `SITE_URL` in `build.py`.

## Leads, blog posts, settings and team
Managed from the **CAS dashboard** (CAS Supabase project). Form submissions go to the `eds-send-lead`
function there; blog posts are written and published from there and saved into `blog/posts/` in this repo.
